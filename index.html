🚀 Application Commands & Installation Guide

Complete step-by-step instructions and shell commands required to configure PostgreSQL, run the Java Spring Boot JDBC backend, and launch the web interface.

Quick Setup PostgreSQL Spring Boot Node.js
1

Environment Prerequisites & System Dependencies

Verify that your local system has the required runtimes installed.

✓

PostgreSQL 12+ (or 16)

Relational database engine running on default port 5432.

✓

Java Development Kit (JDK 17+)

Required to compile and run Spring Boot 3.2 backend.

✓

Apache Maven 3.8+

Build automation tool for managing Java dependencies.

✓

Node.js 16+ (or Python 3)

For zero-config local web server execution on port 3000.

2

PostgreSQL Database Setup & Script Execution

Initialize the callcenter_db database and execute the DDL and DML scripts.

Command Prompt / Bash — PostgreSQL Setup 
# 1. Connect to PostgreSQL as admin (default user postgres)
psql -U postgres

# 2. Create the Call Center Database
CREATE DATABASE callcenter_db;

# 3. Connect to the newly created database
\c callcenter_db

# 4. Execute the DDL Schema script (creates customers, agents, call_records, incidents)
\i schema.sql

# 5. Execute the DML Seed script (inserts records into all 4 tables)
\i data.sql

# 6. Verify table creation
\dt
3

Run Java Spring Boot Native JDBC Backend

Launches the Spring Boot REST API using native HikariCP connection pooling and PostgreSQL.

Terminal — Spring Boot Run 
# 1. Navigate to the backend directory
cd backend

# 2. Build and run Spring Boot application with Maven
mvn clean spring-boot:run

# (Alternative) Package as executable JAR and run
mvn clean package -DskipTests
java -jar target/nexuscall-jdbc-backend-1.0.0.jar
4

Launch Web Application Server (Zero Config)

Serves the responsive web frontend and local REST endpoints on port 3000.

Terminal — Web Application Server 
# Option A: 1-Click Launch on Windows (double-click or run)
start_server.bat

# Option B: Run via Node.js (Zero npm dependencies required)
node server.js

# Option C: Fallback using Python 3
python -m http.server 3000
5

Access URLs & Verification Endpoints

Verify connectivity and interact with the deployed services.
